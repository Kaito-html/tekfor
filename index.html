Perubahan harga dan stok tersimpan real-time di perangkat ini. Hubungkan Google Apps Script agar perubahan langsung otomatis tertulis di Google Sheets Anda.

💡 Tempelkan URL Web App dari Google Sheets Anda di sini, lalu klik "Simpan Pengaturan".

📖 Cara Memasang (Hanya 1 Menit — Sekali Saja):

  1. Buka file Google Sheets Anda: Buka Google Sheets Restoran Mawar Sharon ↗
  2. Di menu atas Google Sheets, klik menu Ekstensi (Extensions) ➔ pilih Apps Script.
  3. Hapus teks di editor, klik tombol "📋 Salin Script Google Apps" di atas, lalu Paste ke editor dan tekan Ctrl + S (Simpan).
  4. Klik tombol biru Terapkan (Deploy) di kanan atas ➔ Penyebaran baru ➔ Pilih jenis Aplikasi web.
  5. Pilih Jalankan sebagai: Saya dan Akses: Siapa saja (Anyone) ➔ Klik Terapkan.
  6. Salin URL Aplikasi Web yang muncul, tempelkan ke kolom di atas, lalu klik "Simpan URL Webhook".
